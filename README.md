# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/temp/1

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

# Timio

Timio is a lightweight time-tracking web app built as a personal MVP experiment using AI-assisted coding. The goal of this project was to explore how AI can support real product design and front-end development workflows.

## Features (MVP)
- Log work hours by client
- Set hourly rates per client
- Export records to PDF or Excel
- Import records from a file
- Simple, frictionless user flow

## Scope
Advanced features such as authentication, user accounts, cloud sync, and gamification were intentionally left out to keep the MVP focused and lightweight.

## Tools
- Visual Studio Code + ChatGPT plugin
- GitHub Compiler
- Cursor
- HTML, CSS, JavaScript (front-end)

## Purpose
This project is a learning experiment to explore a new hybrid workflow where product design, code, and AI coexist in real time. It is not intended as a production-ready application.
